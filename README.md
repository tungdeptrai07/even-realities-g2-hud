# EvenPulse G2 — Heads-Up DeFi, Polymarket & Telegram Whisper HUD for Even Realities G2

**Hackathon:** Heads Up: Even Realities Hackathon ($10,000 USDT Prize Pool)  
**Tracks Covered:** Crypto & DeFi · Messaging & News (Best Telegram Integration) · AI Assistants & Work  
**SDK Stack:** `@evenrealities/even_hub_sdk` · `@evenrealities/evenhub-simulator` · `@evenrealities/evenhub-cli`

## Overview
**EvenPulse G2** is a "Quiet Tech" ambient heads-up plugin for the **Even Realities G2 smart glasses** (`576x136` monochrome green micro-LED waveguide, BLE 5.2, 16kHz PCM mic array, R/L Temple TouchBar):
1. **Crypto, Hyperliquid & Polymarket Lens**: Glanceable perp funding rates, liquidation health factor, and live Polymarket prediction odds.
2. **Telegram Priority Whisper Bridge**: Uses AI urgency scoring (`score >= 60`) to mute noisy group chatter and beam only critical whale/fill alerts and VIP DMs onto the glasses.
3. **16kHz Voice & Coding Agent Supervisor**: Hands-free voice queries and CI/CD build notifications on the waveguide HUD.
